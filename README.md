# Fara Beauty Lounge

Responsive salon website built with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Preview locally

Run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000.

## Files

- `dist/index.html` — page content, contact details and booking links
- `dist/style.css` — visual design and responsive layouts
- `dist/script.js` — service prices, category tabs and mobile navigation

## Hosting

Publish the contents of `dist` with any static website host. This repository does not configure automatic deployment or change the salon's domain.

## External services

Booking and gift-card links open the existing Zenoti service. Photos are loaded from farabeautylounge.com and fonts from Google Fonts. Preserve or migrate the photo files before retiring the original website hosting.

Prices and business information should be reviewed by the salon before public launch.
